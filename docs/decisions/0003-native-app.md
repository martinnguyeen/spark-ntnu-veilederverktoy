# ADR 0003: Egen native SwiftUI-app

Status: besluttet.

Produktet bygges som en egen native macOS-app. Muesli/Wispr Flow brukes som interaksjonsreferanse, ikke som kodebase eller runtime-avhengighet. Dette gir kontroll over lokal lagring, lydlivssyklus, tillatelser og NTNU-spesifikke personverngrenser.
