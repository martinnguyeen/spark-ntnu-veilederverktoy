NTNU IDUN Valgfritt

Oppsummer møter med IDUN når du ønsker det. Transkripsjon sendes bare etter bekreftelse. Krever eduroam eller NTNU VPN.

Nøkkelen beskyttes med Windows DPAPI for din brukerkonto.
3

Innstillinger og diagnostikk

Ser bare etter vindustitler. Starter aldri opptak automatisk.

Ta lokal sikkerhetskopi av datamappen når appen er lukket. Eksporter enkeltmøter som Markdown eller JSON fra møtesiden.

    
Som på Mac slettes rålyd automatisk sju dager etter vellykket transkripsjon. Møtenotatene beholdes. Avbrutte opptak beholdes for gjenoppretting.
